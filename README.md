# SafePulse - SOS Safety App

A mobile safety application designed to provide immediate assistance during emergency situations. With a single tap, the app alerts trusted contacts and records evidence to enhance user safety.



## Features

* One-tap SOS emergency trigger
* Sends live location coordinates via SMS
* Automatically calls the primary emergency contact
* Starts audio recording for evidence collection
* Supports multiple emergency contacts
* Simple and user-friendly interface



## Tech Stack

* Language: Java / Kotlin
* Platform: Android (Android Studio)
* APIs:

  * SMS Manager
  * Location Services (GPS)
  * Audio Recorder



## How It Works

1. The user saves emergency contacts in the app
2. In a critical situation, the user presses the SOS button
3. The app:

   * Sends current location via SMS to all saved contacts
   * Calls the primary contact
   * Starts recording audio



## Purpose

The goal of this project is to improve personal safety by enabling quick communication and basic evidence collection during emergencies.



## Permissions Required

* SMS
* Location
* Phone Call
* Microphone
